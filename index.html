Instrucciones para Colaboradores (GitHub y Servidor Local):

⚡ Modo Local con Excel (Recomendado):

Al descargar o clonar este repositorio, haz doble clic en iniciar_asistencia_qr.bat. Se abrirá el servidor local en http://localhost:8000 y sincronizará en tiempo real con el archivo Excel local.

☁️ Modo Nube (GitHub Pages / Web):

Al alojarse en GitHub Pages o abrirse directamente en el navegador, el sistema se conecta en vivo a Firebase Cloud Firestore (otn-pbregistr), permitiendo registrar asistencia desde cualquier lugar sin necesidad de servidor propio.
